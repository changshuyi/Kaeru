# 追加改動：VJW 新制（7 大機場手機辦海關確認）

貼給 Claude Code。設計稿在 `Kaeru 產品畫面.dc.html`（總覽的「回程當天流程」與 FQA 的「出境時」分區），截圖 `screenshots/01-home.png`、`04-fqa.png`、`09-ja-home.png`。

---

日本數位廳新制：成田、羽田、關西、中部、新千歲、福岡、那霸這 7 個機場，旅客連上機場指定 WiFi 後可以直接在 Visit Japan Web（VJW）辦海關確認，不必排自助服務機。VJW 上會顯示免稅店購買紀錄與海關確認結果（綠色判定等），但**不顯示退款方式的登錄狀態，也不顯示實際退款完成狀態**。

## 1. 回程當天流程的文案

總覽底部的流程清單改成（中文，三處都要改，總覽、RWD 430、RWD 768）：

- `01` 提早 3 小時到機場，行李先不要託運（不變）
- `02` 連上國際線出發大廳的專用無線網路，**開啟** VJW（原本寫「登入」，改成「開啟」，註冊是出發前就該做的事）
- `03` **用 VJW 辦海關確認，或到自助機台掃護照**（原本寫「在免稅手續機台掃描護照，等綠色或紅色判定」，機台已不再是唯一路徑）

日文版：

- `02` 国際線出発ロビーの専用無線 LAN に接続し VJW **を開く**
- `03` **VJW で税関確認、または端末でパスポートを読み取る**

## 2. FQA 新增「出境時」兩題

放在「購買時」之後、「小撇步」之前，沿用現有的問答列樣式（`1px solid #E1DCD5` 上邊、`padding:15px 0`、問題 15px/line-height 1.7、答案 13px/line-height 2 `sub`、`margin:12px 24px 0 0`）：

**Q「什麼是 VJW，要先辦嗎？」**

> Visit Japan Web，日本官方的入出境線上服務，出發前先註冊比較省時間。成田、羽田、關西、中部、新千歲、福岡、那霸這 7 個機場，連上機場指定 WiFi 後可以直接用手機辦海關確認，不必排自助機台。其他機場還是走機台。

下方加一顆線框標籤：`設置位置與操作細節日本官方尚未公布`。**細節不要寫死**，機台設置位置、數量、VJW 連線方式都還沒公布，寫進去會過期。

**Q「VJW 看得到退款進度嗎？」**

> 看不到。VJW 只顯示免稅店的購買紀錄和海關確認結果，退款方式有沒有登記、錢有沒有真的退回來，都不會出現。這兩段要自己記，Kaeru 就是在管這件事。

這一題很重要：VJW 覆蓋的是四段狀態的第 1 段（已購買）和第 3 段（已通過海關查驗），第 2 段（已登記退款方式）和第 4 段（已退款）只有 Kaeru 管得到。這是這個 App 存在的理由，要講清楚。

## 3. 暫時不要動的

出境機場清單的「建議提早時間」先不改。新制的前提是這 7 座不用排機台，理論上可以下修，但官方還沒公布機台配置與 VJW 連線細節，現在調數字是猜的。等官方數字出來再說。

如果之後要加，方向是在這 7 座的列上加一顆線框標籤 `VJW 手機辦`，讓使用者知道自己不必排隊。
