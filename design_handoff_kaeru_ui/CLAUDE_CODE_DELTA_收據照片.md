## 1. 來源選擇（`28-photo-source.png`）

點占位框跳出底部面板，**沿用行程切換面板的樣式**：底層畫面 `opacity:.35`，遮罩 `rgba(73,70,64,.28)`，面板貼底、`border-top:1px solid #494640`、`padding:22px 26px 30px`、不做圓角。

- 標題「收據照片」18/700 + `✕`
- 副標 11.5px `sub`：「照片只存在這台裝置上，不會上傳。」
- 三個選項（列間 `1px solid #E1DCD5`，第一列上方 `#494640`，`padding:16px 0`）：**拍照**／**從相簿選**（副標「最多選 4 張」）／**掃描文件**（副標「自動抓邊框、拉正、去陰影」）。標題 15/700，副標 11.5px `sub`，右側 `›`
- 底部 `1px solid #494640` 後置中「取消」13.5/600 `sub`

iOS 用系統 `UIImagePickerController` / PHPicker，Android 用系統選擇器；這個面板是我們自己的一層，讓「掃描文件」跟另外兩個並列。

## 2. 相機（`29-photo-camera.png`）

**全App唯一的深色畫面**，底 `#494640`，取景區 `#5C5A54`。

- 頂列：取消／「拍收據」／閃光 自動，白字 13px
- 取景區內縮 26px 一圈 `1px solid rgba(255,255,255,.45)`，四角 26×26 的 `2px solid #93A392` 對位標記
- 取景框下方 11.5px `rgba(255,255,255,.75)`：「整張收據放進框內，最下面的稅率金額要拍到」，稅率那幾行是後面 OCR 的關鍵，一定要拍進去
- 即時判定標籤（同一組填色標籤規則，置中排列）：`邊框已對齊` 灰綠、`有點暗` 灰赭。偵測不到邊框時顯示 `找不到收據邊框` 灰赭
- 底部：左相簿縮圖 52×52、中間快門 70×70（`2px solid #fff` 外環 + 白色實心內圈，四方角）、右翻轉

## 3. 相簿多選（`30-photo-library.png`）

- 標題列：取消／「從相簿選」／完成（`blueDeep` 700）
- 次列：左「最近項目 ▾」13.5px、右「已選 2 ／ 4」11.5px tabular
- 三欄網格 `gap:6px`、`aspect-ratio:1`。未選：`1px solid #E1DCD5` + 右上 17×17 空框；已選：`1px solid #77899A` + 右上 `#77899A` 白字序號（**顯示選取順序，不是打勾**，順序決定存檔順序）
- 底部固定列 `border-top:1px solid #494640`：左 11.5px 說明「只存在這台裝置上／存檔時會自動壓縮」，右實心 blue「加入 2 張」（數量跟著選取數變，0 張時淡出停用）

## 4. 確認與裁切（`31-photo-crop.png`）

- 標題列：重拍／「確認照片」／使用（`blueDeep` 700）
- 預覽區 392px 高、`#F4F2EF` 底、`1px solid #E1DCD5`，四角 24×24 `2px solid #77899A` 的可拖曳把手
- 標籤列：`邊框已自動抓好` 灰綠 + 線框 `1.2 MB → 240 KB`（壓縮前後，用現有 `compressImage(maxSide 1000, quality .6)` 的實際數字）
- 三顆等寬工具鈕：**調整邊框**（`1px solid #77899A`、`blueDeep`，主要動作）／**旋轉**／**增強對比**（兩者線框 `#E1DCD5`、`sub`）
- **OCR 區塊**：`#F4F2EF`，左「從照片讀到的金額」11px + 「可以直接帶入表單，之後仍可手動改」10.5px `sub`，右 20/600 `blueDeep` 金額
- 主按鈕實心 blue：「使用這張並帶入金額」

### OCR 行為

- 抓收據下方的合計與稅率分項（日本收據固定印成「8%対象 4,104円（内消費税 304円）」這種格式），優先抓 `合計` / `お買上計` 那一行的含稅金額
- 同時抓到 8% 與 10% 兩組 → 表單的稅率自動切到「兩種都有」並把兩格都填好
- 只抓到一組 → 填單一稅率的含稅金額，稅率跟著抓到的百分比選
- 讀不到 → 這個區塊整塊不出現，主按鈕改成「使用這張」，不要顯示空的或猜的數字
- 讀到的值一律可手動改，**不要鎖住欄位**。OCR 是省打字，不是真相來源
- 店名和日期也讀得到的話一起帶，讀不準就不要帶
