# 追加畫面：匯出與刪除

貼給 Claude Code。設計稿 `Kaeru 產品畫面.dc.html` 的 `2b` 區塊，截圖 `screenshots/58-data-manage.png`、`59-export-options.png`、`60-delete-confirm.png`。顏色用既有色票，不要新增。

隱私說明頁（`56-privacy.png`）的「匯出或刪除全部資料 · 前往 ›」進來。純本機儲存讓匯出成為**唯一的備份手段**，所以匯出不是附屬功能，要跟刪除同等份量。

## 1. 資料管理（`58-data-manage.png`）

- 標題「匯出或刪除資料」21/700 ＋「資料都在這台手機裡，所以匯出和刪除都由你自己操作，不需要通知我們。」
- `1px solid #494640` 後一段用量：「目前存了」+ 右側「3 趟行程」／28px 等寬中粗 `12 張收據` + 右側「照片 18 張 · 24.6 MB」
- **匯出**兩項（列間 `1px solid #E1DCD5`，`padding-top:13px`，標題 14.5/600、副標 11.5px `sub`、右側 `匯出 ›` `blueDeep` 700）：
  - 這趟行程 — 大阪 11 月 · 4 張收據 · CSV 或含照片的 ZIP
  - 全部行程 — 12 張收據 · 24.6 MB
- **刪除**三項（右側 `刪除 ›` 用 **`#8A6448` clayInk**，不是 clay 填色）：
  - 已結束的行程 — 東京 5 月、首爾 2 月 · 8 張收據
  - 只刪照片 — 留下金額，省下 24.1 MB
  - 全部資料 — 12 張收據和 3 趟行程都會消失
- 收尾 `#F4F2EF`：「刪除是立即且不可復原的。這台手機以外沒有備份，我們也拿不回來。」

**刪除要分三級，不要只給「全部刪除」。** 使用者真正的需求通常是「手機快滿了」，那該刪的是照片不是收據 — 「只刪照片」讓他不用二選一。「已結束的行程」則對應「東京那趟辦完了，留著佔空間」。只給一顆核彈按鈕，等於逼使用者放棄整份紀錄。

每一項都要**先寫出會刪掉多少**（8 張收據、24.1 MB），數字放右邊等寬。沒有數字的刪除選項使用者不敢按。

## 2. 匯出選項（`59-export-options.png`）

- 標題「匯出全部行程」＋「12 張收據 · 3 趟行程」
- **格式**兩個單選（`1px solid`，選中 `#494640` + `#F4F2EF` 底、未選 `#E1DCD5` + 白底；右側 17px 圓形 radio，選中 `1.5px #77899A` + 8px 實心圓）：
  - **CSV**（預設選）— 用 Excel 或 Google 試算表打開。金額、店名、日期、稅率、狀態都在，照片不含。42 KB
  - **ZIP（含照片）** — CSV 加上所有收據和物品照片，檔名對得起收據序號。24.6 MB
- **會匯出什麼**三條：每張收據一列（日期、店名、含稅金額、稅額、稅率、狀態、備註）／金額用日圓原值，另一欄放當時的匯率換算結果／**待補的欄位留空，不會填 0 — 空白和零是兩件事**
- `#F4F2EF`「匯出之後檔案就離開 App 了」＋「存到哪裡、要不要傳給別人，由你決定。那份檔案不再受這裡的設定保護。」
- CTA `匯出 CSV`（blue 實心，文字跟著選中的格式變）＋下方 11.5px「會開啟系統的分享選單」

**radio 是唯一該用圓形的地方。** 其他一律四方角 — 圓形在這裡表示互斥單選，跟 checkbox 區分。

第三條「待補的欄位留空，不會填 0」呼應快速新增的待補狀態。如果匯出時把待補寫成 0，使用者拿去報帳就錯了。

「匯出之後檔案就離開 App 了」是隱私上的誠實話：前一頁保證資料只存本機，這裡就得說清楚邊界到哪裡結束。

## 3. 刪除確認（`60-delete-confirm.png`）

置中對話框（`left/right:20px`、`top:50%` `translateY(-50%)`、`1px solid #494640`、`padding:24px 22px`、四方角、遮罩 `rgba(73,70,64,.32)`、底層 `opacity:.3`）。

- 「刪除全部資料？」19/700 ＋「12 張收據、18 張照片、3 趟行程都會消失。這台手機以外沒有備份。」
- `1px solid #494640` 後「會一起消失的」三列，右邊等寬數量：收據與稅額紀錄 `12 張`／收據與物品照片 `18 張 · 24.1 MB`／行程與機場設定 `3 趟`
- `#F4F2EF`「還沒匯出過」＋「要留紀錄的話，先匯出再回來刪。」**匯出過就換成「上次匯出 2026-08-20」**，不要一直嚇人
- 三顆按鈕：`先匯出`（線框，**放最上面、寬度滿版**）／`取消`＋`刪除`（並排，刪除用 `#B08D74` 實心）
- 收尾 11px「刪除後會回到第一次開啟的畫面」

**「先匯出」要比「刪除」顯眼，而且放在最上面。** 這是唯一能救回資料的動作 — 使用者按到這一步通常沒想過要備份。刪除按鈕用 clay 填色但不要放大，不需要用紅色嚇人，把後果講清楚就夠了。

不做二次輸入確認（打「刪除」兩個字那種）。清單已經把後果列完，再加一層是懲罰而不是保護。

## 4. 其他

- 「只刪照片」不需要這麼重的確認，一般 sheet 就好，但也要寫「省下 24.1 MB，金額紀錄會留著」
- 匯出 CSV 的欄位順序照第 2 點那三條，稅率欄位要能表示「兩種都有」（見 `CLAUDE_CODE_DELTA_照片型別.md`）
