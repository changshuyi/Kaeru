# 追加畫面：權限說明與隱私說明

貼給 Claude Code。設計稿 `Kaeru 產品畫面.dc.html` 的 `2b` 區塊，截圖 `screenshots/55-permission.png`、`56-privacy.png`、`57-privacy-ja.png`。顏色用既有色票，不要新增。

前提事實（政策內容以此為準，改了功能就要改文案）：

- OCR **完全在手機上跑**，照片不上傳
- 收據、照片、行程設定**只存本機**，沒有伺服器、沒有帳號
- 唯一的對外連線是**匯率 API**，只送幣別代碼
- 不收使用統計、不收廣告識別碼、無崩潰回報
- 對應台灣個資法與日本個人情報保護法（APPI）
- 聯絡：`sueeloveblack@gmail.com`

## 1. 權限說明（`55-permission.png`）

第一次要用相機或相簿前出現，**不是** App 一開就跳。

- 頂部青蛙標誌 + `KAERU` wordmark
- 標題「要用相機和相簿」22/700，說明「拍收據、或從相簿選圖。照片和辨識都在你的手機上完成，不會上傳。」
- `1px solid #494640` 後兩段對照，各三條（`01`/`02`/`03` blue tabular 序號 + 12.5px/line-height 1.8）：
  - **會做的事**：讀取你選的那幾張照片，辨識金額和店名／把照片壓縮後存在這台手機裡／**就這樣。沒有第三步**
  - **不會做的事**：不會讀取你相簿裡其他照片／不會把照片或金額傳到任何伺服器／不需要註冊，也沒有帳號
- `#F4F2EF` 區塊「不給也能用」＋「照片是選填的。你可以全部手動輸入金額，功能一樣完整。」
- 主 CTA `允許使用相機和相簿`（blue 實心）＋純文字 `先不要，我自己手動輸入`（12.5px `blueDeep` 600）

**拒絕的路要留得體面。** 照片本來就是選填的（見 `CLAUDE_CODE_DELTA_照片型別.md`），所以「先不要」不是降級體驗，不要寫成警告語氣、不要用 clay。

「就這樣。沒有第三步」不是玩笑話，使用者對相簿權限的預設懷疑是「你要拿去幹什麼」，把清單封口比多寫三行保證有效。

## 2. 隱私說明（`56-privacy.png`）

設定頁進去，左上角「‹ 設定」，右側「更新於 2026-08」。**白話版，不是條文。**

- 標題「你的資料在哪裡」21/700 ＋「全部在這台手機裡。Kaeru 沒有伺服器存放你的收據，也沒有帳號可以登入。」
- `1px solid #494640` 後六列（列間 `1px solid #E1DCD5`，`padding-top:12px`），左邊資料項目 13.5px、右邊線框標籤：
  - 收據金額、店名、日期 → `只存本機`
  - 收據與物品照片 → `只存本機`
  - 回程時間、機場、匯率設定 → `只存本機`
  - 文字辨識（OCR） → `手機上跑`
  - 即時匯率 → `會連外網`（副標「只送出幣別代碼，不會送出你的金額」）
  - 使用統計、廣告識別碼 → `不收`
- 「所以會有兩個結果」兩條：離線也能記帳，只有匯率會停在最後一次更新／**刪掉 App 或換手機，收據就沒了**（這句 700 粗體）。要留就先匯出
- `#F4F2EF` 區塊「匯出或刪除全部資料」＋「隨時可做，不需要通知我們」＋ `前往 ›`
- 收尾 11.5px `sub`：依台灣個人資料保護法與日本個人情報保護法，你有查詢、更正、刪除的權利，資料都在你手上，直接操作即可。有問題寄到 `sueeloveblack@gmail.com`。

**表格是這一頁的重點。** 一句「我們重視你的隱私」沒有資訊量；六列各配一個標籤，使用者三秒就掃完。標籤一律用**線框**，不要 clay 填色，這裡沒有一項是警示。

「刪掉 App 收據就沒了」要寫在隱私頁而不是只寫在設定頁。純本機儲存是隱私上的優點、資料保全上的風險，同一頁講完才誠實。

## 3. 日文版（`57-privacy-ja.png`）

同版面，全日文，**不要中日並列**（沿用查驗模式那條規則：標籤跟著介面語言走）。

- 「データの保管場所」／「すべてこの端末の中にあります。Kaeru はレシートを保管するサーバーを持たず、アカウント登録もありません。」
- 標籤：`端末内のみ`／`端末内で処理`／`通信あり`（副標「通貨コードのみ送信。金額は送信しません」）／`取得しません`
- 兩條結果：オフラインでも記録できます／**アプリを削除すると、レシートも消えます**
- 收尾提個人情報保護法與台湾個人資料保護法

日文標籤比中文長，`端末内で処理` 已是最長的一個，三顆一列的排版要以它為基準測。字型 Noto Sans JP，不要襯線。

## 4. 沒做的部分

使用者只要 App 內畫面，**沒有要可列印的法律條文全文**。上架商店需要一份完整政策的 URL，那份還要寫：資料保存期間、兒童資料、政策變更通知、第三方（匯率 API 供應商名稱）。要出的時候再說。
