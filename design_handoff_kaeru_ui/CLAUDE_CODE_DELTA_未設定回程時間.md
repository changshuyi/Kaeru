# 追加改動：還沒設定回程時間的狀態

貼給 Claude Code。設計稿 `Kaeru 產品畫面.dc.html` 的 `2b` 區塊，截圖 `screenshots/52-overview-no-return-date.png`、`53-saved-toast.png`、`54-deadline-pending.png`。顏色用既有色票，不要新增。

---

漏洞：現在的設計假設使用者先建行程、再拍收據。實際上第一次開 App 最急的動作是「我人在店裡，先把這張存起來」，行程資料（回程時間、機場）還沒填。**存完之後沒有任何東西再提起這件事。**

而回程時間是總覽整頁的地基：倒數、期限判斷、當天流程、查驗提醒全靠它。沒有它，總覽只剩金額，App 退化成一個記帳本。

**行程名稱本身不重要**，可以一直是「未命名行程」，不要逼使用者取名。缺的是回程時間，不是名字，所有文案一律講「回程時間」，不要講「完成行程設定」。

## 1. 總覽的缺口（`52-overview-no-return-date.png`）

**不要把倒數區塊隱藏起來**，藏起來就沒人知道少了什麼。原本 52px 倒數的位置換成 `1px dashed #B08D74` 的缺口區塊，`padding:16px`：

- `回程班機起飛前` 10.5px `letter-spacing:0.24em` `sub`（保留原本的段標，位置對得起來）
- 「還不知道你什麼時候回國」19px/700
- 說明「填了回程時間才能倒數，也才算得出每張收據的期限。行程名稱可以不用取。」
- 兩顆按鈕：`設定回程時間`（blue 實心 `flex:1`）／`晚點`（線框）

**金額那段照常顯示**，已經存的收據還是要看得到。含稅合計、預估可退稅額、「已存 3 張收據 · 看清單 ›」。

下方 `1px solid #494640` 後加一段「還算不出來的事」，三列各配線框標籤：每張收據還剩幾天 `期限待定`／回程當天的流程與提醒 `待設定`／出境機場能不能辦、要不要排隊 `待設定`。收尾 `#F4F2EF` 一句「收據先存著沒問題，資料都在。回程時間補上之後，上面這些會一起算出來。」

標題列的行程名寫「未命名行程 ›」，不要空白。

## 2. 存好之後的提醒（`53-saved-toast.png`）

**第一張收據存完、且還沒設定回程時間時**，存好的 toast 加第二段。深色 `#494640`，`left/right:22px`、`bottom:30px`、`padding:15px 17px`、四方角：

- 打勾圖示（`stroke:#B8CBB7`，深底變體）+「收據存好了」13.5/700 白字
- 「順便設定回程時間？填了才能倒數和算期限。」12.5px `rgba(255,255,255,.78)`
- 右上 `✕` `rgba(255,255,255,.5)`
- 兩顆：`設定`（白底深字 `flex:1`）／`再拍一張`（`1px solid rgba(255,255,255,.28)` 線框）

**只出現一次，關掉不再問。** 店裡不是填航班的場合，使用者急著離開櫃台。總覽上方的缺口會一直留著，不需要靠 toast 追。

## 3. 期限待定（`54-deadline-pending.png`）

期限那格現在是空的或猜的，都不對。

- 清單頂部一條 `1px dashed #B08D74` 提示：「3 張收據都還沒有期限」13.5/700 +「期限是從回程時間往回算的」11.5px `sub` + 右側 `設定 ›`
- 每張卡的標籤區掛**線框** `期限待定`（線框＝待補，不是警示，所以不要用 clay 填色）。日期那行寫「2026-11-11」不變，卡片其他狀態標籤照舊並排
- 點 `期限待定` 標籤直接跳去填回程時間，填完**全部一起**換成天數

下方三條說明：

1. 收據本身沒問題，金額照算，只是算不出還剩幾天
2. 點這個標籤直接跳去填回程時間，填完全部一起換成天數
3. **不要猜一個日期填進去。猜錯比空著更危險**

收尾 `#F4F2EF`：「對帳時人通常在飯店，那才是填航班的好時機，所以提醒放在這裡，不是放在店裡。」

## 4. 三個位置為什麼都要做

它們攔的是不同時間點的使用者：總覽的缺口攔每次開 App 的人；toast 攔剛存完第一張、還在店裡的人；期限待定攔在飯店對帳的人。少任何一個都會有人一路走到機場才發現算錯。
