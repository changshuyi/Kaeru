## 1. 說明用字的方向

原本的說明文字偏向公告語氣，讀起來像條款。要改成**口語但不輕鬆**，講清楚後果，不裝可愛，也不用敬語式的句型。

三個要避開的句型：

- `所以…由你自己操作，不需要通知我們` → 因果連接詞堆疊，像法務寫的
- `…是立即且不可復原的` → 名詞化，把動作寫成狀態
- `裝置` → 一律寫**手機**。使用者不會說「我的裝置」

改的原則：主詞回到「你」，動詞用日常詞（走／沒了／幫不上／看著），後果放在句尾。

## 2. 關於 Kaeru（`61-about.png`）

設定頁進去。

- 52px 青蛙標誌 + `KAERU` 15px `letter-spacing:0.3em` 700 `blueDeep` + 「1.0.0 · 2026 年 8 月」11.5px tabular
- **名字的由來**（`1px solid #494640` 段）：「日文的「かえる」同時是三個意思。退稅這件事剛好三個都用上了。」下面三列（列間 `1px solid #E1DCD5`），左邊日文 19px/700 + 羅馬拼音 11px `sub`，右邊中文 13.5/600 + 說明 11px `sub`：
  - `帰る` kaeru → 回家／行程結束前要辦完
  - `換える` kaeru → 換回來／把多付的稅換回來
  - `蛙` kaeru → 青蛙／所以標誌是一隻蛙
- **這個 App 做什麼**：「只做一件事：在你回家之前，把該退的算清楚、別漏掉。哪張沒達到門檻、哪張快過期、機場要提早多久到，這些都幫你看著。」＋ `sub` 一段「不代辦退稅、不碰你的錢，也沒連上海關或免稅店的系統。手續還是在店裡和機場辦。」
- `#F4F2EF`「稅額是估算」＋「規則以日本國稅廳和各免稅店的公告為準。各店手續費不同，實際入帳可能少一點。」
- 兩列連結：隱私說明 `›`／回報問題或建議 `sueeloveblack@gmail.com`

三個 kaeru 那段是這頁的主體，用**對照表**而不是散文，一句話講三個同音字會糊掉，三列一眼就看懂為什麼標誌是青蛙。

「不代辦退稅、不碰你的錢」要寫清楚。使用者裝一個退稅 App 的第一個疑慮是「錢會不會經過你們」，About 是回答這件事最合適的地方，比藏在條款裡好。

「稅額是估算」也放這裡而不是只放 FQA，免責放在 About 比放在使用中的畫面上不擾人，但要找得到。
