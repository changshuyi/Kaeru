# 追加改動：返回與離開

貼給 Claude Code。設計稿在 `Kaeru 產品畫面.dc.html`，截圖 `screenshots/41-menu.png`、`42-back-rules.png`、`43-exit-hint.png`。

---

兩個導覽問題要修：

1. 頁面之間沒有返回的路徑，進了子頁面沒有一致的返回入口
2. 按手機的返回鍵會直接跳出 App，即使使用者只是想從收據頁回總覽

## 1. 選單

標題列的 `≡` **不要另做一頁**，直接用現有的行程切換彈跳面板（`17-trip-switch.png`），在那個面板裡加五個主畫面的列（總覽／收據／查驗進度／FQA／設定），目前那頁右側的 `›` 換成 `目前` blue 填色標籤。

副標可以留（「倒數、金額、回程當天流程」這類），使用者沒有底部分頁列可以認圖示，這個面板是唯一看得到全部功能的地方。

## 2. 子頁面的返回列（`42-back-rules.png`）

**左上角一律寫「‹ 上一頁的名字」，不要只放一個裸箭頭。** 12–13px，`blueDeep` 600。例如詳情頁是「‹ 收據」、出境機場是「‹ 返回」（上一頁是編輯行程，名字太長就用「返回」）。

規則：

1. 左上角這顆、手機返回鍵、左緣滑動，三個做**同一件事**
2. 面板和 sheet 用返回鍵**先關自己**，不要一次退兩層。開著行程切換面板時按返回，只關面板
3. 五個主畫面在同一層：在收據／查驗／FQA／設定按返回鍵，**一律先回總覽**，不是離開 App
4. 深層路徑照堆疊退：出境機場 → 編輯行程 → 行程切換面板 → 總覽

**有未存的編輯時，返回不要直接丟掉。** 新增收據、編輯行程、裁切照片這些畫面，返回時先問「這筆還沒存，要放棄嗎？」，兩顆按鈕：**繼續編輯**（線框 `#E1DCD5`）／**放棄**（實心 `#B08D74`）。沒有改動過的話就直接返回，不要多問。

## 3. 離開提示（`43-exit-hint.png`）

只有**已經在總覽**時，返回鍵才進入離開流程，而且要按兩次。

- 第一次按：畫面底部浮出深色提示條，`left/right:26px`、`bottom:34px`、`background:#494640`、`padding:14px 16px`、四方角
  - 左：「再按一次返回鍵就離開」13/600 白字 + 「收據都存好了，資料不會不見」11px `rgba(255,255,255,.7)`
  - 右：「留下」11.5/700 **`#B8CBB7`**（深底上的灰綠變體，`flex:none`）。原色 `#93A392` 在 `#494640` 上只有 3.53:1，要提亮才讀得到
- 2 秒內再按一次 → 離開 App；超過 2 秒沒動作，提示條淡出，計數歸零
- 提示條不擋操作，點畫面其他地方照常互動

那句「資料不會不見」是重點：這個 App 的資料只存本機，使用者最怕的就是離開後收據沒了。

## 其他

- iOS 沒有硬體返回鍵，靠左緣滑動與左上角那顆。**離開提示條只在 Android 出現**
- 三顆返回相關的可點區域最小 44×44
- 轉場 180–220ms `cubic-bezier(0.4,0,0.2,1)`，返回用反向動畫
- 顏色用既有色票，不要新增
