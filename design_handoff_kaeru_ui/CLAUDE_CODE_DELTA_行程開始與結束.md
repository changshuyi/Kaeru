# 追加改動：行程的開始與結束

貼給 Claude Code。設計稿在 `Kaeru 產品畫面.dc.html`，截圖 `screenshots/38-empty-unnamed.png`、`39-empty-named.png`、`40-trip-ended.png`。

---

現在完全沒有「建立行程」這個動作：App 第一次打開就偷偷生一個空白行程，使用者可以直接開始加收據，完全不會意識到自己在一個行程裡。「行程」這個概念要到使用者自己去點行程切換面板才會第一次被看見。結果是這趟跟下一趟出國的收據會全部悄悄疊在同一個匿名行程裡。

要做兩件事：**空狀態先讓行程被看見**，以及**保守地偵測「這趟結束了」**。不要做強制的首次引導畫面，這是輕量記帳工具，開場擋一道門檻的代價太高。

## 1. 總覽空狀態，行程未命名（`38-empty-unnamed.png`）

判定條件：行程沒有名稱、或沒有回程時間。

- 標題列的行程名位置寫「還沒命名的行程」
- 倒數的位置改放**待填的行程卡**：`1px dashed #E1DCD5`、`padding:22px 20px`。裡面是段落標籤「這趟行程」+「還沒有名字」26/700 `sub` 色 + `1px dashed` 分隔後兩列狀態：`行程名稱`／`回程班機時間`，右側「未填」12.5/600 **`clayInk #8A6448`**（不是 `#B08D74`，那是填色用的）
- 說明 13px/line-height 1.95 `ink`：「收據會存進一趟行程裡。先幫這趟取個名字、填上回程時間，之後的倒數和查驗進度才算得出來。」
- 主 CTA 實心 blue：**「先幫這趟行程取個名字」**，點進編輯行程畫面
- 下方置中逃生口：「或者 **先加一張收據，晚點再填**」（`blueDeep` 600）。**不要強制**，只想快速記一筆帳的人要能直接走
- `1px solid #494640` 後段落標籤「先看懂規則」+ 三條編號摘要（5,000 円門檻／境內消費失效／90 天期限）

**虛線框是刻意的例外。** 票券語彙（實線框）只用在收據頁；虛線在這裡代表「這裡還沒填」，跟照片占位框同一個語意。不要把它改成實線，也不要在其他畫面用。

## 2. 總覽空狀態，已命名但沒有收據（`39-empty-named.png`）

- 倒數正常顯示，標籤列放 `行程已建立`（sage 填色）+ 線框 `関西国際空港 KIX`
- 金額列照正常版面，數字為 `¥0` 且用 `sub` 色（不要用 ink，零不是資訊）
- 收據區塊改成 `#F4F2EF` 填色，`padding:20px`：「還沒有收據」15/700 + 說明「在免稅櫃檯結完帳，就把收據拍進來。同一間店同一天的會自動合併計算。」+ 實心 blue CTA「新增第一張收據」
- 底部一列「先看一遍規則」→「FQA ›」

## 3. 偵測「這趟結束了」（`40-trip-ended.png`）

**觸發條件（兩個都要成立）：**

1. 回程班機時間已經過去 **超過 24 小時**
2. 這趟的收據**全部**已退款或已失效（沒有任何一張還在待處理）

**只提示一次。** 使用者按「先不要」之後，這趟行程不再問。沒有收據的行程不提示。

誤判成本不對稱：漏判只是使用者自己去切行程；誤判會讓人以為舊資料不見了。所以條件要嚴，而且**絕對不要自動建立或自動切換行程**，一律等使用者按。

**版面**：底部面板，沿用行程切換的樣式（底層 `opacity:.35`、遮罩 `rgba(73,70,64,.28)`、`border-top:1px solid #494640`、不做圓角）。

- 標題「這趟看起來結束了」18/700 + 右上 `✕`
- 說明 12.5px/line-height 1.9 `sub`：「大阪 11 月 的回程班機已經飛了兩天，4 張收據也都處理完。要開始新的行程嗎？」，講出判斷依據，不要只說「看起來結束了」
- `1px solid #E1DCD5` 後結算：「這趟總共退回」+ 金額 20/600 `blueDeep`；下方狀態標籤（`3 張已退款` sage、`1 張失效` clay）
- 主 CTA 實心 blue「建立新行程」
- 下方兩個次要出口並排置中：「先不要」（`sub`）／「看這趟的紀錄」（`blueDeep` 600）
- 最後 `1px solid #E1DCD5` 後 11px `sub`：「舊行程和收據都會留著，隨時可以從選單切回來。」，這是誤判時的安全網，一定要留

倒數的顯示：回程時間已過時，**倒數區的標籤和數字都要換**，標籤從「回程班機起飛前」換成「這趟已經結束　帰国済み」，數字換成「已出境」（不要留著「起飛前」配「已出境」，那是自相矛盾）；金額列的標題從「預估可退稅額」換成「已退回稅額」。
