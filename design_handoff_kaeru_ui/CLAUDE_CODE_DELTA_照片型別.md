# 追加改動：照片型別與可存的待補收據

貼給 Claude Code。設計稿 `Kaeru 產品畫面.dc.html` 的 `2b` 區塊，截圖 `screenshots/49-quick-add-no-amount.png`、`50-not-a-receipt.png`、`51-photo-types.png`。顏色用既有色票，不要新增。

---

實務問題：使用者拍進來的圖不一定是收據，可能是買到的東西。目前照片這個欄位同時承擔兩個用途，收據的**憑證**（OCR 來源、金額依據）和購買物的**備忘**（回國後想起這筆買了什麼）。兩者需要的行為完全不同。

## 1. 必要性重新定義

**必填只有金額和稅率**（要算稅額）。店名、日期可以待補。**照片全部是選填**，完整表單本來就能純手填。

所以三條路徑都要能走：

1. 拍照 → OCR 帶入 → 存
2. 純手填（完整表單）
3. **只有照片、金額待補 → 也要能存**

第三條之前被停用 CTA 擋掉了，這是錯的。使用者可能就是想先把圖丟進去，回飯店再算。

## 2. 沒讀到金額時可以存（`49-quick-add-no-amount.png`）

改 `CLAUDE_CODE_DELTA_體驗調整.md` 第 4b 節的兩個地方：

- **主 CTA 不停用**：`#77899A` 實心「存起來，金額晚點補」，下方 11px `sub` 一行「金額補上才會算進預估可退稅額」
- 標籤從 `要填才能存`（clay 填色）**降級成線框**：`金額待補`、`稅率待選`。線框＝待補，clay 填色＝警示，兩者不要混
- 說明改「照片模糊，金額沒讀出來。現在填或晚點補都可以。」

### 稅率也要在這一頁

`稅率待選` 這個標籤原本指向一個不存在的欄位，整頁沒有地方可以選稅率。要補上。

放在「含稅金額」下面、退款登記那題上面，三顆一列（`8%` / `10%` `flex:1`、`兩種都有` `flex:1.4`，`padding:10px 0`，`#F4F2EF` 底 + `1px solid #E1DCD5`，數字 `tabular-nums`）：

- **預設不預選。** 不要猜 10%，猜錯會算錯稅額
- 點 `8%` 或 `10%` → `稅率待選` 標籤消失，只剩 `金額待補`
- 點 `兩種都有` → **不在這裡展開兩格輸入**，直接標成待補、跳到詳情頁再拆。店裡那五秒鐘不塞第二層輸入
- 三顆都沒點也能存，就是留著 `稅率待選`

下方說明「這個你自己知道，不用等辨識。選不出來先留著。」

稅率是使用者自己知道的（買藥妝 10%、買食品 8%），不需要 OCR，反而是最容易當場點掉的一格。少了它，回飯店要補兩件事。

金額待補的收據跟店名待補同一套處理：虛線卡框、不計入預估可退稅額、不參與 5,000 円門檻判斷。標籤寫 `金額待補`。

擋住不如誠實。這個 App 是幫使用者記帳的，不是在考他。

## 3. 「不像收據」的分支（`50-not-a-receipt.png`）

OCR 判斷不出收據結構時**不要沉默失敗**（那就是「¥0」那個 bug 的變體），給第三種狀態。判斷依據可以很粗略，有沒有一串數字、有沒有橫向文字列，不需要精準。

- 照片預覽 200px，中間放 132px 圓角 16px 的 `#DFE5EA` 方塊 + 46px 圖片圖示（`stroke:#8B857D`、`stroke-width:1.5`）
- 標籤 `不像收據`（clay 填色）
- 標題「這張看起來不像收據」19/700，說明「沒有讀到金額和店名。如果這是買到的東西，可以存成物品照片；如果是收據，換個角度、把整張拍進去會比較好讀。」
- `1px solid #494640` 後三條說明（`01`/`02`/`03` blue tabular 序號 + 12.5px/line-height 1.8）：不跑辨識不影響金額／一張收據可放多張／標錯隨時可改回
- 三顆動作：**存成物品照片**（blue 實心）／**重拍收據**（線框）／**還是當收據，我自己填金額**（純文字 11.5px `blueDeep` 600）

使用者的誤操作變成一個有用的分支，不是錯誤訊息。

## 4. 照片型別（`51-photo-types.png`）

**不要做成兩個欄位。** 一個附件區，每張圖帶一個型別：

- 拍照或選圖 → 預設當收據照，跑 OCR
- 讀到金額 → 帶進欄位
- 讀不到或不像收據 → 問一句（第 3 點），使用者可改標成物品照，這張不再參與 OCR
- **型別隨時可改**（長按縮圖切換）

使用者不需要在拍照前先決定要拍哪一種。那個決定放在拍完之後，而且可以改。

詳情頁的附件區：

- 段落標籤「照片　4 張」+ 右側「＋ 加照片」12px `blueDeep` 600
- 分兩組，各有 11.5px `sub` 小標「收據照片　1 張」／「物品照片　3 張」
- **收據照片**：74×96 的收據縮圖，`1px solid #494640`，左下角掛 `憑證` 標籤（9px/600 白字、`#77899A` 實心、四方角、貼齊邊角不留 margin）
- **物品照片**：74×74 方形縮圖網格，`gap:9px`，最後一格 `1px dashed #E1DCD5` 的 `＋`
- 下方 11.5px `sub`：「長按任一張可以改型別。物品照片不跑辨識，也不影響金額。」
- `#F4F2EF` 說明區塊「為什麼要分兩種」：憑證那張要拿給海關看，也是金額的來源；物品照片只是備忘

**新增流程不要多問。** 預設拍收據，存完之後才在詳情頁出現「加照片」，不要在店門口那五秒鐘裡多塞一個決定。

## 5. 清單怎麼顯示

物品照片**不影響收據卡的狀態判讀**，不要進卡片主體。卡片右下角一個線性相機圖示 + 數字（`3`），點了看圖。金額、達標、期限這些判讀資訊的位置一格都不讓。

物品照片也不進 OCR、不進金額推算、不觸發「沒讀到金額」那套提示。
