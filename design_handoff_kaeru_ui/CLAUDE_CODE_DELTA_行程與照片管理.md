原型缺兩塊功能：行程只能建立和切換，不能改名或改出發時間；照片存進去之後沒有檢視和刪除。照現有 2a 視覺語彙（無卡片、分隔線、留白、金額等寬中粗、四方角），色票用既有的，不要新增。

## 1. 編輯行程（`32-trip-edit.png`）

行程切換面板裡的每一列，以及設定頁的行程列，都要能點進這個編輯畫面。

標題列：取消／「編輯行程」15/700／儲存（`blueDeep` 700），底線 `#494640`。

欄位（底線式輸入，段落標籤 10.5px/700 `#77899A` `letter-spacing:0.22em`）：

- **行程名稱**，16px，focus 時底線 `#494640`
- **回程班機時間**，16/600 tabular + 日曆 icon，下方 11.5px `sub`：「改了回程時間，總覽的倒數和建議抵達時間會跟著算。」中文不用「出發時間」，避免被讀成出發去日本；日文維持 `出発便`
- **出境機場**，16px + `›`，點進獨立的選擇畫面（`36-airport-picker.png`）。日本機場很多，不能用下拉：頂端底線式搜尋欄（可搜機場名或三字代碼），下方依地區分組（關西／関東／中部・北海道・九州…），每列左為機場日文名 14.5px + 副標「城市 · 建議提早 X 小時」11px `sub`，右為代碼 12px/700 `sub` `letter-spacing:0.06em`，已選那列名稱轉 700 並加 `已選` blue 標籤。組標題用段落標籤，組內第一列上邊 `#494640`、其餘 `#E1DCD5`。底部「其他機場 ›」給清單外的情況，套預設 3 小時。

  清單放 **34 座有國際線的機場**（依 2026 航季的定期國際航線），不是精選清單。版面：搜尋欄固定在上、地區籌碼列橫向捲動、機場清單在畫面內垂直捲動（`flex:1; overflow-y:auto`），組標題 `position:sticky; top:0` 白底。整個手機外框仍是 844，不溢出。

  分組（照日本國內慣用的地區劃分，主要樞紐拉到最前面）：**主要樞紐** NRT／HND／KIX／NGO／FUK；**北海道** CTS／HKD／AKJ；**東北** SDJ／AOJ／HNA／AXT／FKS；**関東** IBR；**中部・北陸** KMQ／KIJ／TOY／FSZ；**関西** UKB；**中国** OKJ／HIJ／YGJ；**四国** TAK／MYJ／KCZ；**九州** KMJ／KOJ／KMI／OIT／HSG／KKJ；**沖縄** OKA／ISG／SHI。

  建議抵達時間：NRT／KIX 3 小時 30 分；HND／NGO／FUK／CTS 3 小時；區域主力（SDJ／HKD／AKJ／UKB／HIJ／KMQ／FSZ／KOJ／OKA）2 小時 30 分；其餘地方機場 2 小時；清單外一律 3 小時。這個值餵給總覽的「建議抵達機場」和「回程當天流程」第一條，**不要寫死 3 小時**。

  搜尋狀態（`37-airport-search.png`）：可搜日文名、中文城市名、三字代碼；命中的字用 `blueDeep` 700 + `1px solid #77899A` 底線標出；結果數 11.5px tabular「3 個結果 · 也可以輸入 FUK 這種代碼」。結果底部保留「其他機場 ›」，並提醒伊丹空港（ITM）目前沒有國際定期航班、出境要到関西国際空港，這是關西旅客最常搞錯的一件事。
- **設為目前行程** 開關，副標「新增收據時預設存到這趟」

`1px solid #494640` 後**這趟的收據**：`4 張 · 含稅合計` 左、金額 18/600 右；下方三顆狀態標籤（待處理 blue、已退款 sage、失效 clay），數字跟著實際資料。

最後 `1px solid #E1DCD5` 後：12px `sub` 警告「刪除行程會一起刪掉這 4 張收據和照片，無法復原。」+「刪除這趟行程」（`clayInk` 文字 + `1px solid #B08D74` 底線，不做填色按鈕）。刪除要二次確認，沿用照片刪除的底部面板樣式。

改名或改時間**不影響任何收據的狀態或期限**（期限算的是購買日 +90 天，跟出發時間無關）。

## 2. 詳情頁的照片縮圖列（`33-photo-thumbs.png`）

詳情頁原本是一個 96px 高的空框，改成縮圖列：

- 段落標籤「收據照片」左，右側「整理」11.5/600 `blueDeep`（進入排序模式，可拖曳換順序）
- 縮圖 **72×96px**、`1px solid #E1DCD5`、`#F4F2EF` 底、`gap:8px`、`flex:none`（不壓縮）
- 每張右上角 20×20 `#494640` 白色 `✕`，貼齊縮圖邊緣（`top:-1px;right:-1px`），**直接刪這一張**
- 左下角 9.5px 序號 `01`/`02`/`03`
- 最後一格：`1px dashed #E1DCD5` 的 72×96，`＋` 17px + 9.5px「再加 1 張」。已達 4 張時這格不出現
- 下方 11.5px `sub`：「點縮圖放大檢視，右上角 ✕ 刪除。最多 4 張。」
- 底部 `#F4F2EF` 區塊：「照片只存在這台裝置上。刪掉收據時照片會一起刪掉。」

## 4. 刪除確認（`35-photo-delete-confirm.png`）

底層照片 `opacity:.4`，遮罩 `rgba(73,70,64,.55)`（比其他面板深，因為底層本來就是深色），面板貼底白底、`border-top:1px solid #494640`。

- 標題「刪除這張照片」18/700
- 說明 12.5px/line-height 1.9 `sub`：「這張收據還有另外 2 張照片，刪掉這張不影響金額和狀態。刪除後無法復原。」
- **只剩一張時文案要換**：「這是最後一張照片。刪除後這張收據就沒有照片紀錄了。」
- `1px solid #494640` 後兩顆等寬：取消（線框 `#E1DCD5`、`sub`）／刪除（實心 **`#B08D74`** 白字 700）

刪除是唯一用灰赭做實心按鈕的地方，破壞性動作，刻意跟主色的 blue 區隔開。
