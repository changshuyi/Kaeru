刪除資料說明

Kaeru（開發者：shu.developer.tw@gmail.com）

Kaeru 沒有帳號系統、沒有伺服器，你的收據、照片、行程設定全部只存在你自己的手機裡。 刪除資料完全不需要聯絡我們，你自己在手機上就能立刻完成。

怎麼刪除

  1. 打開 Kaeru App
  2. 點右上角「☰」（功能選單），選「設定」
  3. 點「資料管理」
  4. 依你要刪除的範圍選擇：
    • 「只刪照片」——留下金額紀錄，只清空照片
    • 「刪除已結束的行程」——只刪已經過期的行程跟收據
    • 「刪除全部資料」——所有行程、收據、照片、設定一次清空
  5. 確認後立即生效，不用等待、不用審核
資料保留期限 沒有額外保留期。按下刪除的當下，資料就從你的手機裡完全移除，我們這邊沒有伺服器留著任何副本可以刪——因為本來就沒有收過。 如果你直接把整個 App 移除安裝，效果一樣：所有資料跟著解除安裝一起消失，沒有殘留。

有問題可以寄 shu.developer.tw@gmail.com， 但刪除資料本身不需要透過我們，你自己在 App 裡就能完成。

データ削除について

Kaeru（開発者：shu.developer.tw@gmail.com）

Kaeru にはアカウント機能もサーバーもありません。レシート・写真・旅程設定はすべてお使いの端末内にのみ保存されます。 データの削除に当社への連絡は不要で、端末上ですぐに完了します。

削除方法

  1. Kaeru アプリを開く
  2. 右上の「☰」（メニュー）から「設定」をタップ
  3. 「データ管理」をタップ
  4. 削除する範囲を選択：
    • 「写真のみ削除」——金額記録は残し、写真だけ消去
    • 「終了した旅程を削除」——期限切れの旅程とレシートのみ削除
    • 「全データを削除」——すべての旅程・レシート・写真・設定を一括削除
  5. 確認後すぐに反映されます。待機や承認は不要です
データの保存期間 追加の保存期間はありません。削除した瞬間に端末から完全に消去されます。当社にはサーバーがなく、そもそもデータを受け取っていないため、削除できる複製もありません。 アプリ自体をアンインストールした場合も同様に、すべてのデータが消去され、残存しません。

ご不明点は shu.developer.tw@gmail.com までご連絡ください。 ただし削除自体は当社を介さず、アプリ内でいつでも完了できます。
